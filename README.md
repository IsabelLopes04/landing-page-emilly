#  Landing Page — Dra. Emilly Fernandes

Landing page institucional desenvolvida para a **Dra. Emilly Fernandes**, profissional da área de Odontologia em Caraguatatuba - SP.

O projeto foi desenvolvido com foco em apresentar os serviços odontológicos, diferenciais profissionais, informações de contato e localização de forma moderna, elegante e responsiva.

##  Sobre o Projeto

A página tem como objetivo proporcionar uma presença digital profissional para a clínica, facilitando o contato de novos pacientes e apresentando os principais serviços oferecidos.

### Principais seções

-  **Início**
-  **Sobre a profissional**
-  **Serviços**
-  **Diferenciais**
-  **Localização**
-  **Contato**
-  **Instagram**
-  **WhatsApp**

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Google Fonts
- Responsividade para dispositivos móveis
